
# MediTrack Validation Checklist

**Project:** MediTrack Appointment System

**Version:** 0.1

**Prepared by:** Student A and Student B

## Purpose

This checklist is used to validate the MediTrack Software Requirements Specification (SRS).

It helps identify unclear, incomplete, inconsistent and missing requirements.

## AOUT Rules

- A - Atomic: Each item asks only one question.
- O - Observable: The answer can be found by inspecting the SRS.
- U - Unambiguous: Every question has a clear meaning.
- T - Traceable: Every question has a clear reason or source.

## Checklist Notes

1. Every item must follow AOUT rules.
2. Yes is always the good answer.
3. Each item must be answered Yes, No or N/A during validation.
4. Every No answer must include a requirement ID and a one-line reason.
5. Uncertain answers must be marked with a question mark (?).
