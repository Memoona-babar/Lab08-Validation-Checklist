
# Lab 02 - Build a Validation Checklist and Use It

## Project Name
MediTrack - Online Appointment System

## Course
Software Requirements Engineering (SRE)

## Project Description
This project focuses on validating the Software Requirements Specification (SRS) of MediTrack, an online appointment management system for CityCare Clinic.

The purpose is to identify unclear, incomplete, inconsistent and missing requirements before the clinic signs the software development contract.

## Team Members
- Student A: Memoona Babar 043
- Student B: Arwa Ahmad 051

## Project Structure
- srs/ : Contains the MediTrack SRS document.
- checklist/ : Contains the validation checklist.
- runs/ : Contains independent validation results of Student A and Student B.
- findings.md : Contains the agreed validation findings.

## Project Objectives
1. Build a validation checklist.
2. Check the SRS using the checklist.
3. Identify requirement problems.
4. Compare results of both students.
5. Prepare final validation findings.
